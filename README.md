# UPBIDO

**Bid Up. Move Up.**

UPBIDO is a competitive paid-visibility leaderboard for brands, creators and businesses.

## Current stage
Frontend MVP foundation. Demo data only; payments are not connected yet.

## Run locally
```bash
npm install
npm run dev
```

Rankings are paid/sponsored positions and do not represent quality or popularity.


## Global launch bid rules (USD)

UPBIDO uses USD as the primary bidding/ranking currency globally. Initial minimum qualifying bid floors are: #1 $50; #2 $35; #3 $25; #4–10 $15; #11–50 $10; #51 onward $5. Participation remains unlimited.

These are eligibility floors, not guaranteed fixed rank prices. If a target position is occupied by a higher eligible bid, the challenger must place a qualifying outbid. Production ranking uses settled eligible payments only.

Payment collection may be processed in a payer's supported local currency by the eventual payment provider, while UPBIDO records the standardized eligible bid value in USD. Payment-provider availability and country-specific compliance remain separate from leaderboard currency.

## Participation and bidder value

Participation is unlimited; UPBIDO does not stop at 100 participants. Positions #51 and beyond retain a $5 minimum qualifying entry floor under the initial global USD structure, while every participant can retain an exact Global, Country and Category rank. Public leaderboards may use pagination/search while the underlying ranking remains unlimited.

Bidder benefits planned for production include: stronger visual placement for higher positions; direct website/social/store traffic links; simultaneous Global + Country + Category exposure; impressions, profile views, outbound clicks and CTR analytics; shareable rank cards; verification indicators; winner and Top-rank achievement badges; Hall of Fame recognition; public profile pages with rank history; outbid alerts; search-discoverable public pages where indexing is appropriate; and traffic attribution from UPBIDO. Early launch members may receive a permanent Founding Bidder badge.

Top positions are scarce sponsored advertising inventory. Benefits and visual prominence can increase by tier, but paid rank never represents product quality, popularity, customer satisfaction or an independent endorsement.
