# UPBIDO

**Bid Up. Move Up.**

UPBIDO is a competitive paid-visibility leaderboard for brands, creators and businesses.

## Current stage
Frontend MVP foundation. Demo data only; payments are not connected yet.

## Run locally
```bash
npm install
npm run dev
```

Rankings are paid/sponsored positions and do not represent quality or popularity.


## Launch bid rules (Pakistan)

Minimum qualifying bids: #1 Rs 5,000; #2 Rs 3,500; #3 Rs 2,500; #4–10 Rs 1,500; #11–50 Rs 1,000; #51+ Rs 500. These are eligibility floors, not guaranteed rank prices. An occupied rank requires a qualifying outbid. Production ranks must use settled eligible payments only.


## Participation and bidder value

Participation is unlimited; UPBIDO does not stop at 100 participants. Positions #51 and beyond retain a Rs 500 minimum qualifying entry floor at Pakistan launch, while every participant can retain an exact Global, Country and Category rank. Public leaderboards may use pagination/search while the underlying ranking remains unlimited.

Bidder benefits planned for production include: stronger visual placement for higher positions; direct website/social/store traffic links; simultaneous Global + Country + Category exposure; impressions, profile views, outbound clicks and CTR analytics; shareable rank cards; verification indicators; winner and Top-rank achievement badges; Hall of Fame recognition; public profile pages with rank history; outbid alerts; search-discoverable public pages where indexing is appropriate; and traffic attribution from UPBIDO. Early launch members may receive a permanent Founding Bidder badge.

Top positions are scarce sponsored advertising inventory. Benefits and visual prominence can increase by tier, but paid rank never represents product quality, popularity, customer satisfaction or an independent endorsement.
